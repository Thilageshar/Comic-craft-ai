🎨 ComicCraft

ComicCraft is an AI-powered comic creation platform that helps users turn their ideas into creative comic stories.

✨ Features

- 📝 Enter a story prompt
- 👤 Add character names
- 🌍 Choose the story setting
- 🎭 Select the tone of the story
- 🎨 Choose an art style
- 🖼️ Select the number of comic panels
- 🤖 Generate a comic based on the given inputs
- 📚 Create creative and engaging comic stories easily

 🚀 How It Works

1. Enter your story prompt.
2. Enter the character name.
3. Choose the setting.
4. Select the tone.
5. Choose an art style.
6. Select the number of panels.
7. Generate your comic.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- AI / Generative AI
- GitHub

🎓 Project

ComicCraft is developed as part of the Naan Mudhalvan project.

👨‍💻 Purpose

The main goal of ComicCraft is to make comic creation simple and accessible by using AI to transform user ideas into visual stories.
